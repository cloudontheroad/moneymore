# 可成交整数股数规划：研究阶段

## 已实现

Qlib继续输出连续目标，新增整数投影/执行规划层，不改变预测模型。使用CVXPY调用HiGHS混合整数线性规划；本机CVXPY 1.9.2、HiGHS 1.15.1，依赖已声明在ai可选组。不是自己写股票买卖启发式或新Alpha。

先最小化股票与现金对目标的L1偏离，再在同等跟踪误差内提高股票资金利用率。若先单独最大化股票投资，满仓账户会因任何交易都产生费用而倾向不动，因此不能把这个顺序反过来。现金仍是0%目标的一部分，不设置新的40%仓位限制。

同时约束：

- 非负持仓、实际资金预算、估计滑点、单票上限和目标总仓位上限；不借用应收股息。
- 继承连续优化的标准化风格边界及20%股票袖套L1换手，不因整数不可行自动放松。
- 买入按100股网格，科创板买卖最小200股，不足200股卖出余额须全额卖出。科创板这里只使用合法但更保守的100股增量子集，尚未开放其允许的1股增量。
- 现有零股可保留，或在可卖数量充足时全额卖出；不生成非法部分零股卖出。可卖量和可买/可卖标志作为输入强制执行。
- 科创板单笔按市价口径最大50,000股、其他股票保守单笔上限1,000,000股；本轮不拆单，避免拆单后最低佣金变多而失真。
- 手续费采用现有项目配置和transaction_fee同一公式，含最低佣金、过户费、卖出印花税；最低佣金通过整数分段建模，不只用不等式下界，也不允许零数量交易虚构佣金。
- 先卖后买，净卖出收入较大的先执行。买入可利用本轮卖出净收入，解决逐股按旧现金检查而误拒的问题。

两阶段均需求解状态optimal，默认每阶段10秒；超时/不可行不输出订单。输出前按整数股数重新计算费用、现金、风格、集中度、可卖量及换手；非有限值、负预算或越界均拒绝。只剔除每项不超过1e−6的求解尘埃权重，总尘埃质量超过1e−5则拒绝。支持集为非尘埃连续目标、现有持仓及待上市权益，不声称覆盖全池所有可选替代股。

## PaperBroker连接验证

已增加显式研究用精确股数转换，不再次逐股四舍五入，也不再次用卖出前旧现金拒绝计划内买单。小场景测试用现有PaperBroker验证：前日买入持仓次日按T+1卖出、卖出资金支持买入、先卖后买序列、实际成交后现金与规划费用一致、数量与账本对账通过。

这不是接上真实券商，也不是63次历史计划已经全部完成连续撮合。每个研究计划仍标记 `PASS_REFERENCE_QUOTES_ONLY`、`orders_enabled=false`、`future_prices_used=false`。

## 离线历史快照协议

对已有七组完整风格分支的63次调仓，从当时真实模拟持仓、现金和保存预测重建同一Qlib目标，然后在信号日收盘报价上规划。评分文件哈希与旧回放一致，使用已留档停牌证明与同一120日风险输入，不偷看第二天开盘价或收益。

因为计划是下一交易日执行，本批可卖量按当晚已持有A股股数在下一开盘T+1可卖处理，不代表当日盘中即可卖出；待上市股票权益的基准转换未完成时单列阻断。未使用下一日涨跌停、停牌或跳空信息保证成功。失败只能解释为当前支持集、边界、报价和资金下不可行，不是全市场绝无可行组合。

这些是从旧路径快照分别启动的单步反事实，不是新整数策略自己的连续账本，不能计算或宣称新的策略收益。原先53次实际成交偏差的统计没有被这个离线规划覆盖或抹掉。

## 已发现并修复的问题

首轮独立费用复核挡住部分方案，追踪发现：零持仓科创板的最小卖出量被算为0，允许开启零数量卖出标记并多计最低佣金。已改为无论是否有持仓，开启卖出标记都必须有正数量，并补充回归测试；旧失败结果没有作为委托提交。

## 尚未完成

### 连续回放引擎接入（2026-10-27，基础验收）

后续进度：已完成全量独立整数连续回放及账本重建复核，详见 [全量连续验收](INTEGER_CONTINUOUS_REPLAY_20261027.md)。下文保留本阶段当时的基础验收口径；54/63参考报价单步结果仍不能当作连续执行结果。

新增显式可选的开盘规划回调；默认回放行为不变。新模式先结算公司行为，再用开盘价估值独立账户，向规划器仅提供 open/can_buy/can_sell，禁止传入当天收盘及高低价。收盘仅保存信号，不同时提交旧的逐股取整委托；开盘撤销残留待执行委托，再提交带前一收盘信号日的精确股数，保持规划的先卖后买顺序。

成交后以同一开盘价重新核对实际股数及费用后现金，任何差异立即停止该研究路径，不能把部分成交记作计划通过。不可行计划只留审计记录并保留持仓，不生成替代委托。持有股票缺少开盘估值则明确阻断，不按零价格计算。

新增两个连续场景：跳空后重新规划并连续两天撮合对账；不可行时收盘目标不会绕过门禁提交。与整数规划测试合计14项通过。**目前仅完成引擎与合成闭环，不是七组历史账户已完成整数连续回放**；历史信号、风险快照与公司行为权益的开盘上下文适配及全量结果仍待完成。未更改生产策略、真实委托或历史收益。

### 本轮63次参考报价验收结果

最终54次通过、9次在当前支持集及硬约束下不可行；费用模型修复后没有遗留费用复核失败。54次共生成610条研究参考订单，**没有提交到生产账本或真实券商**。

独立复核：最低预计现金3.44元；最大L1换手0.1999999717；最贴近风格边界的一项仍在边界内约2.16e−6个标准化暴露单位。预计股票仓位约87.53%—99.99%，并未强行声称每次都能达到100%。分组通过数：0815/0905/0912/0926/1003各8次，0829/0919各7次。

这些不是54次成功成交，也不是连续策略收益。9次不可行保持阻断，未自动放宽原风格或换手限制。三组生产权益表运行前后哈希一致。

新增规划及相关回归共40项测试通过，包括零持仓科创板不得虚计最低佣金、科创板最低申报数量、零股全额卖出、现金可卖限制、先卖资金回用及PaperBroker对账。求解器偶发内部数值警告的根因仍需复核；已加强非有限解、实际重算费用和风格的出口阻断，不把警告问题宣称根治。

下一步是接入独立连续回放的开盘前规划/复核：只读取届时可见的开盘或实时报价、当前持仓与成交状态，重新计算资金和股数，按精确股数撮合；遇到不可行或异常要显式暂停/延续持仓，而非执行旧的错误股数。然后重做实际成交风格偏差及成本后收益比较。普通全现金清仓目标、真实送转权益和股息补税仍需各自协议，不把当前股票袖套研究扩张成完整实盘风控。
