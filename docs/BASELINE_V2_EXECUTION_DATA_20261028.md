## 范围与隔离

本次针对冻结权重实验 `20261028T042935817182Z-5d508d59` 的181只月度前十联合股票，补2024-01-31至2025-12-31的官方涨跌停价、停牌记录，以及每股全部分红送转历史。这是月度信号配对实验的数据准备，不是正式日度组合回测完成，也不意味着学习权重通过了收益门禁。

所有新增文件在 `state/baseline-v2-validation/execution-data/`，不写生产日线、涨跌停、分红表，也不修改模型、委托、持仓和权益。

## 下载与验收规则

- 串行限频，每次请求开始之间至少1.3秒；命令有明确请求上限、每个响应独立落盘、文件SHA256和请求参数校验、可断点续传。
- 保留成功的空表及查询范围，不用“无分红事件记录”代替“已完成查询”。响应达到接口返回上限时阻断，不把可能截断的数据称为完整。
- 接口异常立即停止并进入30分钟冷却；不保存可能含凭证的原始错误消息，不盲目重试。使用独立SQLite同步锁，不占用生产账本锁。
- 涨跌停逐行检查日期、代码、有限正数、上下界；停牌只有`S`且全天时间段为空才能作为全天停牌证明，盘中停牌不能豁免全天价格缺口。
- 上市日期以前不需要价格，但这类豁免不能用于上市后的缺口。停牌只解释不成交，不会在这里伪造开盘价。
- 分红送转继续复用已有公司行为处理器，核对公告、登记、除权、支付/股份上市时间和送转比例，避免送股与转增重复计数；逐日复权变化与官方事件交叉检查。
- “所有接口查询完成”不等于“所有数据一致”，也不等于已取得原始公告修订版本。后续回测仍须注明现金分红税费假设。

使用Tushare官方[每日涨跌停价格接口](https://tushare.pro/document/2?doc_id=183)与[分红送股接口](https://tushare.pro/document/2?doc_id=103)。采用按股范围查询，避免将单次全市场返回限制误当全市场已完整覆盖。停牌使用项目已有`suspend_d`适配器；没有回退QMT。
