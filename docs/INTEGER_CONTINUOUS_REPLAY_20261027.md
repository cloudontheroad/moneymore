# 开盘整数连续回放与账本复核

## 验证协议

这是2026-10-12至2026-10-26的事后机制诊断，不是未见样本外收益。枚举主GRU与全部已保存候选，不只检查1010。每个账户分别建立无命名风格约束的Qlib PCA对照、Qlib可行风格约束两个独立连续账本，初始资金相同，使用同一已保存预测、整手申报、手续费、滑点、涨跌停和公司行为规则。

两条路径首次均从同一保存目标通过整数规划建仓，不在第一天人为降低风格。之后各自只读取自身真实模拟持仓，不每日重置回旧账户。风格分支沿用前一收盘确定的完整风险池标准化因子与边界，开盘按当时报价重新求整数股数；换手以自身开盘股票袖套为基准。无风格对照仍执行相同资金、集中度和整数交易约束，不额外增加命名风格限制。

开盘规划只收到 open/can_buy/can_sell，不收到当天收盘、高低价或未来收益。当前日收盘生成的信号只能在下一交易日执行。既有停牌证明及120日完整风险输入门禁保留；未上市股票的历史不能补零。待上市送转权益的整数基准转换尚未支持时显式暂停，不能当作现金或已上市可卖股票。

## 三层核对

1. 整数求解器出口重算费用、股数、现金、集中度、换手和风格边界。
2. PaperBroker成交后核对实际股数及现金，使用冻结因子与实际开盘股数价值重算风格。任何不匹配停止该研究路径。
3. 独立只读脚本读取SQLite成交及公司行为流水，逐日重建持仓、现金，再用正式开盘价核对各次已通过计划及风格边界，不依赖规划器自报暴露。

不可行整数计划的当日不下单，持仓继续承担当日涨跌、保留费用后净值并计入暂停天数；这不是已完成目标调仓。Qlib优化失败或实际成交复核失败的路径标记阻断，不输出完整收益。两种失败不混为一谈。

## 适用边界

这是隔离研究适配，不是实盘订单管理，不自动晋级、重训或替换当前模型。使用实施公司行为的税前现金股息，持有期补税未建模；历史复权因子的未解释跳变风险仍存在。开盘可见价格撮合是模拟假设，不承诺实盘可成交，也未证明盘中及全天稳定性。样本短、方案在观察这段行情后提出，不能按本窗口收益直接选赢家。

## 本轮全量结果

共22条路径（主GRU及10个候选 × 两个分支），15条完成整个窗口，7条明确阻断。完成路径中的137个通过计划，从实际成交与公司行为流水重建的股数、现金均匹配；最大现金误差约1.60e−10元。风格分支共57个通过开盘，包含7次共同初始建仓和50次带风格边界的后续规划；重算后没有边界超限，最贴近的一项仍在边界内约1.77e−5个标准化暴露单位。

风格分支另有13个开盘暂停：12次整数可行性无解、1次达到本次求解时间上限（不能等同数学无解）。持仓按实际继续记收益，未执行旧股数、放宽风格/换手或补造交易。这说明执行边界已能守住，但尚不能做到每个交易日都有可执行的新组合。

结论：整数规划修复了已执行方案的风格落地缺口，但风格约束不是统一有效的收益改良器，特别是1010出现明确反例。下一步优先分析1010的选股与风格交互、暂停机会成本，以及0926的原生优化器换手回退；之后才制定预先固定的滚动样本外协议，不能用本窗口反向选择约束强度。46项相关回归通过；Qlib/HiGHS仍存在偶发数值警告，保留严格状态与独立复核，不宣称求解稳定性已经根治。
