# MoneyMore 建设纲要

更新：2026-10-30。只维护目标、阶段、依赖与验收；调试细节和旧决策移入研究档案，不再向顶部追加流水账。

## 1. 目标与边界

建设本地独立运行的A股研究、模拟、行情、执行与对账系统。研究复用Qlib；行情用已验收接口，不恢复MiniQMT外接依赖。真实交易另行验收，本轮不发送真实委托。

训练必须学习最新可用信息，但不能把近期科技股亏损全归因于训练滞后，也不强制每周换股或给科技比例配额。必须同时检验目标、特征、风格暴露和组合构造。

## 2. 系统建设地图

| 主线 | 已有能力 | 剩余重点 |
| --- | --- | --- |
| 数据 | 历史入库、财务补齐、实时估值/分钟接入 | 全池覆盖、盘中质量、时效及恢复验收 |
| 因子基线 | 原基线与独立基线V2 | V2首轮实际运行闭环与前瞻观察 |

| 执行 | 计划、撮合、日内执行、补偿、对账 | 运行连续性、数据保护、真实客户端另行验收 |
| 产品运维 | 组合/Qlib/仓位页面、本地守护 | 运行与训练解耦，故障可定位，页面显示结论 |

### 4.1 时间与评估协议

1. 截止日为最近已完成交易日，另核对全池数据质量。文件最大日期不是完整性证明。
2. 五日标签只在结束日数据可用后成熟；训练/验证/测试边界清除跨段标签。所有归一化只在相应训练段拟合。
3. 保留126日验证、126日测试作兼容研究对照，新增逐周walk-forward，模拟历史每周当时可见信息。禁止在同一测试段反复调参至通过。
4. 研究确定超参与轮数后，部署模型单独使用截至当期的全部成熟标签重拟合，不再机械排除最近一年。最后5个未成熟日只能做特征/预测，不能带标签训练。
5. 扩展历史与有限滚动窗口作为预登记对照，防止多年旧数据淹没新趋势；窗口/衰减在验证段选择，不按10月亏损挑漂亮回放。
6. 分别记录原始数据末日、共同完整日、最新成熟标签日、实际训练末日和预测日；标签越过可用截止立即阻断。

### 4.2 每周从宏观到微观的必做过程

- 宏观：利率/流动性、汇率、通胀与景气，使用合法接口与真实公布时点；月度数据不前填未来修订。没有历史可用时点的字段先作观察，不进回测训练。
- 市场：全池/指数收益、波动、回撤、量额、宽度和相关性；检查动态候选池与幸存者偏差。
- 中观：行业、市值、价值、成长、动量、波动的强弱和拥挤；上市板块与科技行业分开审查。
- 微观：个股价量、流动性、公告可用财务、公司行为；保留缺失标记，禁止通过缺失后重分配权重悄悄改公式。
- 每周状态快照必须生成。是否将状态特征加入模型，由固定旧特征、增加市场上下文、增加风格/财务的消融对照决定，不把宏观文字判断直接换成仓位公式。
- 新特征需新的输入与模型版本，不强塞旧12通道模型；不新增拍脑袋的30/30/25/15公式。

### 4.3 每周产物与发布决策

质量快照 → 市场/风格周报 → 时间/标签审计 → 滚动评估 → 最新部署拟合 → 同日新旧比较 → 发布或维持结论。

每项记录哈希、截止时点、耗时、失败原因；区分“完整学习后不变”和“缺数据未训练”。相似不是唯一淘汰理由，稳定但有效的模型应保留；差异也不等于改善。过程不依赖大模型自由看新闻。

### 4.4 本周新增：集中偏好三项迭代（2026-10-30）

| 编号 | 必做工作 | 本周末应交付 | 生效边界 |
| --- | --- | --- | --- |
| W4-A | 拆分LightGBM、5个GRU与50/50混合 | 各自Top10、上市板块/行业分布、同日分数相关及样本外指标，定位是谁带来集中 | 先消融，不因单轮结果直接改混合权重 |
| W4-B | 审查标签与风格捷径 | 行业相对标签与绝对收益对照、分数对市值/动量/波动的相关、分组暴露；缺证据显示未完成 | 相对同行排名高不等于绝对看涨；另立目标版本才能改训练，不偷换旧模型 |
| W4-C | 复用Qlib风险组合构造 | 同一分数的原Top10与风险优化权重/跟踪误差/有效持股数/风格对照；优化失败显式列出 | 离线研究，不强制科技配额、不恢复行业等预算，不自动下单 |

执行顺序A→B→C，三个诊断纳入本地周训练后处理，不依赖Codex。最近完整交易日为当期比较日；这周末指2026-10-31，沿用本地每周六09:00计划，服务未开按已有恢复机制补跑。训练完成与诊断完成分别记录；不能把缺少研究证据或优化失败说成有效改进。

接入进展：本地run_weekly_training.py已串研究产物校验→有限停牌取证→最新成熟标签重拟合→selection-review。研究完成的重试不重复训练；完成研究与重拟合的原生退出码仅在产物完整时处理。review.json记录逐模型Top10/行业/上市板块、分数风格相关、原生风险优化对照与明确失败；替代标签训练尚未实现，不能说本周已改为绝对收益目标。风险优化采用已有实验参数仅作诊断，不据此自动改变交易配置。13项相关回归通过，周末整轮自动运行仍需现场验收。

用户查看重点：本周和上周同口径选股差异，以及同次训练不同模型/不同组合构造的差异。不能保证含科比例下降，更不能先按科技数量挑结果。尚未通过滚动验证的新目标、新混合权重和风险方案不得静默作用到旧模拟账户。
