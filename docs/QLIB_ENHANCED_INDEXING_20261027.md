# Qlib原生增强指数优化：离线接入首版

## 已实现与未实现

直接调用已安装Qlib的EnhancedIndexingOptimizer及StructuredCovEstimator（PCA），未复制/改写优化目标或求解器源码。本机原先缺少原生实现固定使用的ECOS，已安装ecos 2.0.14并列入ai可选依赖。

本阶段是**20261026单时点目标权重反事实**，不是历史绩效回测、训练后效果证明、独立模拟账户或实盘计划。现有策略、订单、成交和收益未替换，原财务表、推荐表及三个权益表执行前后哈希一致。

策略适配模块：src/moneymore/research/enhanced_indexing.py；固定协议：configs/enhanced_indexing_research.yaml；运行脚本：scripts/research_enhanced_indexing.py。

## 原生数据链路

1. 主GRU/1010保存的当日原始预测，不重新训练或修改排名信号。
2. 120个交易日复权日收益，截止信号当日，无隐式向前填充缺口；收益使用小数单位，显式关闭Qlib风险估计器默认的百分数缩放。
3. Qlib PCA提取10个统计风险因子、因子协方差及个股特异方差；不是命名风格因子或Barra模型，不能把PC1命名为科技因子。
4. 基准为同一当日已记录评分池、通过风险数据资格的股票等权。它是参照，不是要求实际持仓等权，不设行业预算或行业配额。
5. 股票袖套总仓位保持100%；现有实际股票持仓归一化作为起始权重，不通过增加现金制造改善。不是把旧账户含现金的实际收益和满仓新组合直接比较。
6. 单股上限沿用15%，L1换手上限20%（买卖两边合计，完整投资状态通常约对应单边10%）；不承诺固定十只，避免持股数约束与风险控制不相容。
7. 实验网格固定风险厌恶1/10/100；仅诊断市值与相对基准市值中性两种消融。不依据本时点结果选择赢家。

## 市值控制真的传入，但不是改了旧基线

中性组将当日已可见total_mv的标准化log市值，作为实际列追加到Qlib优化器F矩阵，f_dev该列为0；PCA列边界使用数学上非约束性的全区间，不人为设行业/科技配额。市值额外列的风险协方差为0，避免与PCA风险重复计算，其作用是显式暴露约束。

市值中性是**相对本组等权基准的组合暴露中性**，不是“每只股票市值相同”，也不是旧基线评分预处理已经修复。旧基线保持控制组。新组目前没有行业中性、价值/成长/动量/波动命名因子中性，不得宣传为全风格中性。

每次实验保留实际F、协方差、个股方差、原始分数、起始权重、基准、log市值、收益矩阵、配置和原生优化器代码哈希，能检查控制变量确实存在，不只是显示开关。

## 原生回退保护

本机Qlib实现首轮求解失败可能移除换手约束重试，最终失败可能返回旧权重。适配器不修改该源码，但会捕获日志并独立复核：权重有限、非负、总和为1、个股上限、L1换手、市值暴露；求解失败回退、求解不精确或越界均BLOCKED，不输出可用权重。不会以“程序未抛错”作为验收。

## 停牌与未知缺口严格区分

最初1010被输入门禁挡住：持仓688146.SH在20260623/24/25缺日线。Tushare停复牌接口确认为3个全天停牌日，原始证明已留档。因此仅在风险矩阵中按连续已知前价携带；未写虚构行情、未伪造成交。日内临停、未知缺口、首日无前价仍不填，不能排除一只无法估计的持仓后继续做组合。

最终两组各964只有效风险股票，12个组合计算均通过出口检查。排除的评分股票名单和停牌处理逐项留档。

## 第二阶段：按时间成熟的信号校准

已新增独立只读脚本 `scripts/calibrate_enhanced_indexing.py --as-of 20261026`。
采用横截面百分位、相对当日保存股票池的5交易日复权收益，逐日等权OLS校准；每个测试日只读取提前成熟且隔离一个交易日的训练标签，至少20个完整成熟预测日。不调网格、不自动反转负信号，不接入交易账户。此OLS是显式的基础校准诊断，不冒充Qlib自带仓位策略。

本轮结果：主GRU有34个完整且按时记录的成熟日，13个滚动样本外测试日；10月26日可用训练斜率为−0.006698（5日收益/居中百分位单位），样本外MSE改善为−0.00015163，低于零收益预测。该结果不支持直接把分数当正向预期收益输入优化器，也不能根据负斜率自动做反向策略。

1010仅2个完整成熟日，不具备校准条件。这里要求整个保存评分池两端价格/复权因子完整，与原前瞻评估允许95%覆盖不同，故计数更低；缺失名单、未成熟日期、原预测哈希与行情文件哈希均记入 `state/enhanced-indexing-research/calibration.json`。没有自动填补缺失收益或使用事后重建预测。

边界：5日测试标签仍重叠，不按独立样本计算显著性；5日斜率除5仅为单位换算，不等于通过日频预测检验。尚未完成收益单位与风险期限一致的优化对照、独立连续账本成本撮合及前瞻观察，不能称为增强策略收益回测。下一步应先审计完整标签缺口，再增加非重叠测试及冻结协议下的优化/执行对照。旧策略、模型和历史收益不变。校准与原生优化相关9项测试通过。
