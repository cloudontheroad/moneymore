# 基线V2：连续整数交易配对实验

## 实验边界

窗口2024-01-31至2025-12-31，464个交易日，初始现金各100万元；比较原冻结九因子固定权重与Qlib Ridge学习权重，在同一评分处理、历史月末候选池和每月前十等权组合下的执行结果。

**这里的固定权重对照不是线上原基线净值；月度前十等权也不是正式V2的日度组合构建。** 学习权重和评分沿用之前的冻结面板，未趁本轮观察结果重新调参。测试期早已用于研究，本次属于历史执行机制验证，不是新增未见样本外证明；原面板也尚未以清洁数据重建。

## 固定执行口径

- 月末收盘信号，下一个交易日开盘参考价规划并撮合；没有信号当日或回填历史开盘成交。
- 目标股票总仓位100%，单股上限15%；复用已有HiGHS整数成本规划器、PaperBroker和公司行为经济应收处理。
- 佣金万1.5、单笔最低5元；卖出印花税万5、双向过户费万0.1、单边滑点2bps。是冻结的模拟参数，不冒充个人账户历史结算费率。对应配置 `configs/baseline_v2_replay.yaml`。
- 普通买入100股整手，科创买入最少200股，送转产生的零股按现有整数规划器处理。先卖后买，费用和现金预算一并求解。
- 只凭官方全天停牌证明延续估值；停牌不成交，涨跌停保守阻断成交，带滑点价格也不能越过涨跌停边界。每月已执行其他交易后，受阻股票持续停牌时不对整组每日再平衡；只在受阻方向恢复可执行时重试，或由下个月信号替换。
- 登记日确认权利，除权日计入现金/股票应收，派息与股份上市时才成为可用现金或股份。模型主表为股息税前，另有统一扣20%股息的保守敏感性场景；它不是实际按持有期FIFO补税模拟。
- 无额外市场择时或回撤止损叠加。配置中的max_drawdown仅沿用模型字段，本实验不声称执行了15%止损。持仓漂移与实际回撤照实记录。
- 开盘加滑点仍是历史参考成交模型，不代表真实盘口深度、成交价或容量保证。

## 账本与工程验收

每组独立SQLite数据库，保留逐日权益、委托、成交、尝试、公司行为权利与入账。另从成交和公司行为流水独立重建每一天的现金、持股、市值、未付现金及未上市股份应收，核对经济权益，误差上限一分钱。逐笔检查开盘价格模型、手续费、停牌/涨跌停和买入整手，所有成交信号必须早于成交日。

回放曾暴露两处工程问题，旧结果不得采信：

1. `20261028T073122Z-de273280`：学习组第二阶段求解不可行，导致9月未执行。保留原文件，并以post-run-audit标记44个阻断计划，禁止作为收益结论。
2. `20261028T074415Z-6f200838`：修复次级求解后，持续停牌期间仍每日对全组重规划，出现4次求解超时。该轮状态为BLOCKED，不采用其收益。

修正：初级必须确认为optimal；初级不可行或超时绝不接受。次级仅为已最优方案的投资额择优，次级异常不能抹掉初级解；可恢复保存的初级解，但仍须通过同样的整手、现金、费用、权重、风格、换手及市场约束精确复核，并逐次标记fallback，不宣称该次次级优化成功。重试改为受阻交易恢复时触发，而不是持续停牌期间每日改仓。未通过复核时仍阻断。

## 最终有效本轮结果

有效实验目录：`state/baseline-v2-validation/continuous-replays/20261028T075110Z-91ab4d53/`。四组均464日，规划阻断0，逐日独立账本重建误差最大约0.0000000021元，所有成交价格/费用/停牌/涨跌停/整手检查通过。学习组两种股息场景各有1次初级最优方案恢复、5个已确认停牌等待日；没有把未求得最优的初级解放行。全部结果仍为研究诊断，不是真实历史成交证明。

最终74项相关回归测试通过，静态检查通过，API健康状态正常、模拟模式与本地调度开启。未启动真实委托，也未恢复暂停的候选V2账户。

不能忽略逐年分化（主场景）：2024-01-31起的2024片段，固定+19.78%、学习+46.71%；2025全年固定+26.51%、学习+14.37%。累计学习权重领先16.26个百分点，主要优势来自2024；2025仍明显落后。此前统计稳健性不足的结论没有因此被推翻。

下一建设优先级：正式日度组合构建/换手规则的同条件回放，并按年份、风格和尾部持仓解释收益差异；原面板完整池数据版本审计另行保留。不能事后挑2024去证明最优、也不能根据2025单独反复调权重。最终V2不自动发布，暂停实验组不恢复交易。

## 后续建设与命令

本实验完成后还需验证正式日度组合规则，并审计完整训练池的数据版本、金融修订与风格稳定性。不能仅因累计收益较高就自动晋级；必须同时查看逐年差异和成本。候选V2保持暂停，线上原基线与其他模型及其历史收益不改。
