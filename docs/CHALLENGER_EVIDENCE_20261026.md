# 挑战体系：前瞻评估、风格归因与处置

## 实施边界

只补市场数据和派生证据；没有重跑旧预测、训练模型、改权重、补造交易、调整收益历史或向真实券商下单。手动入口：

`python scripts/review_challenger_evidence.py --as-of 20261026`

脚本在运行前后核对三份权益历史文件SHA256及成交条数。每日流水线在候选执行后运行该诊断，再运行原有漂移和长期评审。既有漂移降级规则仍有效；新的建议表本身没有状态变更或委托权限。

## 1. 前瞻评估

旧函数没有调度，结果文件停在20260803。新评估批量读一次区间行情，覆盖主账户和各训练版本：

- 用SSE交易日历确定 t+5，不将停牌/缺行情误当交易日不存在；仅用as-of及以前可见标签。
- 主口径与现有训练一致：原始收盘价5日收益，按报告当时sector去均值。它不是实际可执行的T+1净收益，也没有改成复权训练目标。
- 同日多份预测选择最早记录；保留SHA256、生成时间和文件名来源。生成时间必须在当日收盘后、下一交易日开盘前，才有时间资格进入成熟前瞻日；事后重建仅作诊断。
- 95%截面覆盖且选中股票标签完整、IC可定义，才计入可用成熟日；否则列出缺失股票、覆盖率和状态，不把整天静默丢弃、不把未定义值写成0。
- 本地生成时间不等于独立时间戳公证。成熟前瞻日是预测标签计数，不等于候选生命周期20/40/60日的可信权益共同日，更不代表已通过全部晋级门禁。5日标签相互重叠，不按独立样本做显著性结论。

数据修复后：主GRU51个成熟日，近20日平均IC −0.0520；7个有效候选成熟日为6、8、11、13、20、25、29，平均IC均为负。原预测及成交没有因补数而改写。

崇达技术等部分持仓缺少20260907—20260928间15个交易日，而旧特征按存储行shift/rolling，把缺口两端当成相邻记录。查到缺口不等于证明它是亏损的唯一原因。

未来训练/推理按交易日历显式插入缺失NaN，不再压缩时间；收益特征禁止隐式前填，缺口污染的序列不参与模型截面；当前日没有合格截面则明确报错，不能用过期分数生成订单。既有模型未重新训练，不能宣称本轮修复已经使模型恢复有效。

## 3. 风格匹配归因

共同区间：20261012收盘至20261026收盘，11个快照、10个收益日。限定当前1000股方案之后，并不改变各策略完整权益曲线。

以前一日真实持仓市值/权益作为权重，从前一日记录的预测候选池中选择同交易板块、对数市值/20日动量/20日波动百分位距离最近的5只非持仓股票。近邻不根据当日收益或当日数据选择；同时输出3和10近邻的敏感性，不按表现挑邻居数。行业仅作展示，不进入预算分配。

日收益分解：

- 市场：前一日股票仓位 × 当时记录候选池的等权收益。
- 风格：匹配篮子收益贡献 − 市场贡献。
- 选股：原持仓收益贡献 − 匹配篮子贡献。
- 费用：实际当日费用 / 前日权益的负值。
- 交易及其他：实际净收益扣除上述项目后的残差，包含日内持仓变动、执行、公司行为/税、现金等差异，绝非纯交易择时能力。

以实际净值财富链接每日贡献，使五项之和等于同区间实际净收益。缺失数据不前填、不用未来值；PARTIAL只表示匹配成功子区间，不能冒充全区间归因。本次9组账户均10/10日完整，校验误差在浮点精度范围内。
