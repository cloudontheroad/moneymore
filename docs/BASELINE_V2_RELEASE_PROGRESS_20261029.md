## 风控执行缺陷及V2修正

独立复现原平台的粘性账户风险状态后发现：进入“减仓/只卖”时，执行入口却暂停全部订单，而不是落实对应限制。两年内固定375日、学习351日遭风险阻断；这是保留持仓的冻结，并非清仓止损。

新V2研究适配器遵循现有风险目标，不另造择时公式：

- NORMAL：按模型目标执行。
- REDUCE_ONLY：目标不超过当前持仓权重，并在执行规划中禁止买入。
- SELL_ONLY：显式清仓意图，允许完整零股卖出；停牌/无法卖出时保留持仓等待再次执行，未上市送股权益不提前卖。
- SUSPENDED：所有订单冻结。
- 风险状态继续粘性保留；没有新增自动解锁或自动恢复买入逻辑。

修正仅用于隔离V2回放，不改变原平台/原账户行为。合成回放已验证风险触发后的卖出、反弹不重新买入、停牌等待及暂停全停；完整两年修正版回放启动后，必须用其真实结果判断风险合同，不能沿用无止损参考的收益。
