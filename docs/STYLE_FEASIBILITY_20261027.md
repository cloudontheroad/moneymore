# 风格约束可行性与新股风险历史审计

## 本轮建设

继续复用Qlib原生EnhancedIndexingOptimizer。新增的是求解前的标准凸优化Phase-I可行性层，不是一个新的选股信号或收益预测模型。它不读取未来收益、不按回测收益选择收敛强度。

原做法每天要求四项风格偏离同时至少降低25%，但20% L1换手预算可能不够。新做法先在同一个股上限、全投资、非负权重及换手预算下，求解最小的“最大残余风格偏离比例”；将25%压缩保留为研究目标，如果达不到，显式减弱收敛目标，再由Qlib原生收益—风险优化决定最终权重。

数学协议：相对同池等权基准的标准化暴露为e；最小化t，约束每个风格的目标绝对偏离不超过t×当前绝对偏离，且0≤w≤15%、sum(w)=1、L1(w−w0)≤20%。存在可行解后，Qlib使用保留比例max(0.75,t+0.001)，上限1。0.001是避免贴可行性边界的数值余量，不是根据收益选择的仓位参数。无法在不恶化当前暴露的前提下满足其他硬约束，仍中止，而非放松换手或个股集中度。

可行性LP通过ECOS求解并独立复核可行权重见证；Qlib最终结果再次复核相同硬约束。不能把Phase-I成功等同于Qlib数值求解成功，更不能把它等同于未来收益改善。新分支将原生求解迭代上限提高至1000，其他分支维持200，求解不精确/回退超限仍拒绝。原始0.75研究目标本身尚未做冻结参数的独立前瞻检验，不是已经训练出的最优值。

官方机制参考：[CVXPY线性规划](https://www.cvxpy.org/examples/basic/linear_program.html)、[Qlib原生优化器](https://github.com/microsoft/qlib/blob/main/qlib/contrib/strategy/optimizer/enhanced_indexing.py)。Phase-I组合适配逻辑是本项目新增，不能宣称Qlib自带此渐进收敛策略。

## 风险历史缺口：已查明，不伪造补齐

正式证券基础资料核实：301666.SZ于20260416上市、688808.SH于20260424上市。两者在回放初期的120日风险窗口均跨到上市前。

进一步通过2次有界停牌接口查询核实301666在20260519/20/21全天停牌；5月22日的缺收益由前一停牌日缺价格传导，并非5月22日又缺正式行情。当前审计缺价格日期共10个上市前日期和3个正式停牌日期，没有剩余未解释价格缺口。

只对有正式全天停牌证据的日期允许在研究风险矩阵中携带前一已知价格；文件和哈希已保存并接入后续回放。上市前不填价格、不填零收益，不删除已经持有的新股来求解。默认120日协议仍保持不变，因此主GRU、0812、0822的优化分支仍可能被阻断。这是协议下历史样本不足，不是继续向数据商查询就能补出的行情。

若后续允许不足120日的新股，需要单独冻结短窗/收缩风险估计协议，并与原120日组合并行验证；本轮没有以观察到的收益为理由自动缩短窗口。

## 验收与产物

新增Phase-I“只减弱目标、不放宽换手”的测试、集中度冲突拒绝测试、缺口分类测试，以及与原生Qlib联动的出口约束测试；相关回归共26项通过。

风险审计：`state/enhanced-indexing-research/risk-history-audit.json`。每次回放保留LP最小可行比例、实际采用比例、是否减弱目标、可行权重见证、原生优化输出审计，不将“收敛目标减弱”隐藏成正常严格中性。

连续回放增加第四条 `style_feasible`，同时保留原目标、普通PCA、固定压缩25%的旧分支作为对照，旧研究目录不覆盖。仍是事后机制消融、税前股息口径，不自动晋级、不改生产账户。

## 全候选实际运行结果

本轮11账户×4路径，共44条；26条完整、18条阻断。可行性优先风格分支有7组完整通过，3组受上市前风险历史阻断（主GRU、0812、0822），1010在10月22日被原生求解的换手出口检查挡住。不能将4组未完整通过的策略按零收益计入排行。

所有完整的可行性分支目标L1换手均在20%上限的数值容差内，最大0.2000000033，没有靠放开换手通过。七组均发生过至少一次收敛目标减弱，逐日保留LP见证和采用比例。生产三组权益表哈希不变。
