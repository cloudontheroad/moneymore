# N3结项：固定预测的风险与成本感知交易对照

日期：2026-11-12。状态：**N3研究及工程核验完成，当前成本优化配置不采用，不等于新策略已发布。**

## 1. 最终判断

完整特征DoubleEnsemble的排名选股在本轮历史中明显优于三个消融对照，但当前“线性收益校准→风险/成本优化”没有保住这个优势。不能说本轮没有任何进步，也不能说风格均衡与盈利目标都已实现。

- 保留完整特征DoubleEnsemble预测与TopK作为后续研究对照，不重训覆盖现有模型。
- 保留已验证的成本计算、风险约束与A股执行实现；**不把本版cvx_cost配置晋级或替换生产策略**。
- 本轮到N3结束，N4/N5/N6未执行。后续若继续，必须正视收益校准失效与行业集中，不再把低换手或低回撤单独作为成功标准。

## 2. 同口径完整结果

4组固定预测×3组合器×10/20bps=24个独立研究账户。每账户1000万元；2026-01-05至2026-09-30共181个交易日。正常20交易日换仓，非换仓日仅处理真实退池卖出。单边滑点之外另计佣金、最低佣金、印花税和过户费；252日年化，无风险利率0。

TopK为50只、保留drop5缓冲的排名对照；cvx_risk为原生cvxportfolio收益—风险优化，cvx_cost在同一优化框架内增加交易成本。优化组具有个股、行业相对基准和换手约束，**TopK不具有相同的行业/换手约束**；因此优化组与TopK的差异不能全部归因于成本项。隔离成本项应看cvx_cost相对cvx_risk。

## 3. 差异的直接证据

### 预测向收益转换基本失效

校准使用当时已成熟的历史样本外预测，固定规则为20日收益横截面线性斜率均值减一个20日区块标准误、下限0。36个“模型×月份”中，**35个beta_conservative为0**。

- 三分数Ridge、完整特征Ridge、Alpha158 DoubleEnsemble的9个月全部为0。这解释了它们的优化账户结果相同，并非串用了成交账户。
- 完整特征DoubleEnsemble仅1月非零，为0.0000212096（每个标准化分数单位的20日期望相对收益）；2—9月为0。
- RankIC衡量排名关系，不等于原始经济收益的线性斜率，更不等于扣除估计误差后仍有正收益。当前转换没有把排名优势传给优化器，优化主要由风险、基准、成本与已有持仓驱动。
- 未事后改校准阈值、反转分数、调风险系数或按2026收益挑参数。下一阶段不能直接把这条转换当作已有效的预测收益输入。

### 降换手确实生效，但没有实现帕累托改进

完整特征DoubleEnsemble下，成本组相对风险组年化换手从1.17降到0.72，约减少38%；手续费从15,418元降到3,220元，成交从2,504笔降到511笔。净收益多0.92个百分点，但最大回撤多2.00个百分点，且实际仓位高17.80个百分点，不能把收益差全部归功于省费用。

相对TopK，成本组换手约少69%，但净收益少11.46个百分点、夏普低1.158、回撤多0.80个百分点。省成本不能补偿丢失的持仓收益。成本组并未同时改善净收益、夏普和回撤。

### 风格与现金都不能隐藏

- 完整特征DoubleEnsemble TopK的银行平均占净值44.82%，电子17.76%；创业板＋科创板平均占净值8.18%。后者不等于科技行业含量，不能以“含科少了”宣称风格均衡成功。
- 成本优化组最大单行业权重的日均值降到18.93%，风格分散确实发生，但没有实现收益目标。
- 整手向下取整和实际可交易限制令不同组合现金残留不同：风险组实际平均仓位77.29%，成本组95.09%，TopK99.03%。低波动/低回撤不能直接当作预测改进，也不能把设定99.5%股票目标当作已成交仓位。
- TopK季度收益为+1.23%、+0.07%、+8.62%；成本组为−1.29%、+5.74%、−5.57%，全期指标不能代替分期稳定性。

同日配对、20日环形区块、2000次重采样下，10bps成本组相对TopK的净收益差95%区间为[−29.99，+5.86]个百分点，跨零；20bps也跨零。没有做多重比较校正。这是历史诊断，不是统计上证明未来必然优劣。

## 4. 工程修复与验收

三项确认的执行缺陷已修复并纳入测试：

1. 停牌股票缺当日评分/市值，不再误冻结整个组合：可核实历史风险时仅冻结该股，真正风险缺失仍保护。
2. 风险滚动窗口若从停牌中间开始，先用当时已知、官方停牌证明支持的窗口前价格延续，再截取窗口；不得填补未知缺口或使用未来价格。
3. 待卖退池股票在非换仓日重试，只处理退池卖出，不反复触发其他股票的全组合优化。

最终权威产物仅为`n3-full-matrix-v4`与`n3-final-v4`，旧v1/v2/v3保留诊断，不拼接旧净值。64次连续解缓存复用要求输入、协方差、求解器源码及原结果哈希完全吻合；模拟撮合和账本全部从初始资本重放。

- 24×181=4,344条决策独立核验通过。
- 160次连续优化的资金、上下限、行业、换手约束复核通过。
- 24账户逐日对账，以及独立现金重建、逐证券数量、成交导出和订单关联检查通过。
- 58个“账户×日”的个股冻结记录均未错误交易；76个退池专用处理日无额外买入/换仓；32个未能立即卖出的退池记录保留可交易性限制，不虚构成交。
- 最终无整组合保护阻断记录，不代表保护已关闭，也不保证其他行情永不触发。
