# S4/S5：风格约束的独立机制核验

证据：state/style-balance/constraint-mechanisms-20261102-b/results.json。a版保留，b版增加源控制/风险/分数哈希与非有限约束输入阻断。无新模型、无新账户、无委托。

## 冻结的测试合同（非生产风险预算）

799只当前全字段完整风险子集，按同日总市值归一为参照；不是1000完整市场，更不是历史PIT基准。起始权重设为该参照，不是原模拟账户持仓。单股最高15%、单次L1换手20%、命名风格/行业/上市板块主动暴露严格为0。零偏离用来证伪“约束只是配置没生效”，不是通过收益选择的最终交易参数，也不是行业等预算。

## 方法与结果

实际调用Qlib EnhancedIndexingOptimizer，风险使用既有PCA分解，命名控制作为额外显式约束，不以PCA代替价值/成长控制。4种分数：科技行业全部极高、银行全部极高、创业/科创全部极高、最近完成模型分数。每种有/无命名约束，共8次求解。

用独立CVXPY公式、Clarabel求解器交叉核验相同风险/分数尺度/约束；这不是已经集成cvxportfolio，后者仍待做。所有结果预算、单股边界、换手和命名暴露均独立检查；发现Qlib放宽换手、回退或不准确求解即BLOCKED，不能因原生函数返回权重就PASS。

8项均PASS_MECHANISM_ONLY，跨求解器目标值差约1e-10—5e-9。严格约束下：创业/科创14.6999%、科技行业20.1863%、银行22.3103%，各自等于该风险子集基准；不是三个固定配额。科技行业定义此处为申万电子/计算机/通信，上市板块另列。

原Top10在极端科技/创业科创用例可达100%集中；在相同换手约束下，仅启用风险目标而不绑命名边界，仍可出现显著主动偏离。真实分数在此799子集的原Top10为90%创业/科创，与原965评分池Top10的100%不是同一可投集，不混报。

严格约束真实分数对应有效持股数约80.6，而不是10只；说明“硬锁Top10”与强风格中性可能冲突。不能为了通过约束偷偷买799只或声称此持股规模适合个人账户；容量、资金量、整数化、成本与合理风险带宽仍须后续选择。
