# N系列：完整预测—组合—交易重建

授权日期：2026-11-12。目标：交付可执行、可归因的新独立模拟方案，而不是继续增加审查模块或承诺无法保证的收益。

## 2. N1/N2有限实验协议

N3后续已完成[N3R](ASHARE_RANK_PRESERVING_RESULTS_20261112.md)和[N3R2](ASHARE_RANK_CADENCE_RESULTS_20261112.md)。当前研究候选`rank_cap`在10/20bps为27.85%/25.76%收益、1.428/1.341夏普、12.56%/12.85%最大回撤。用户明确接受合理风险增加，不以同时支配每个旧风险指标为研究前提；生产发布仍与历史研究分开。N3R2的10日更新/drop5未提高收益夏普，不替换该候选；下一依赖是新增独立预测信息，而非降仓、微小订单阈值或追加周期网格。

- 新目录：`state/ashare-mainline-20261112/`；配置：`configs/ashare_mainline_v1.json`。
- 已有输入：原生Alpha158快照、R系列修复标签及公告日约束的财务细项。新输入仍有历史池快照沿用、供应商历史修订等局限，不称完全原始PIT。
- 首版分别输入EP、BP、ROE、营收同比、ROE变化、营收变化、6—1/12—1月动量；不是三个平均分。毛利/现金流等尚未覆盖字段明确列为未接入，不为可选财务原文收集卡住训练。
- 市场状态来自当日历史池的真实价格收益、均线宽度、历史波动/回撤；仅截至信号收盘。不把市场指标人为加权成总仓位。
- 唯一主标签：信号后下一交易日开盘至20交易日后收盘复权收益；训练标签按日横截面排名标准化。经济收益原值另存，不把rank解释为预期收益。
- 2025Q1至2026Q3逐季测试。每折内部最近60个可用信号日作验证；训练标签结束严格早于首个验证日，验证标签结束严格早于首个测试日。预处理只拟合训练集，标签缺失不删除推理样本。
- 固定4组：三分数Ridge、完整特征Ridge、Alpha158 DoubleEnsemble、完整特征DoubleEnsemble。相同日期、候选行、标签、预处理规则。只按完整矩阵汇报，不看首折决定删掉差的组。
- 官方DoubleEnsemble：3子模型、样本重加权＋特征选择、28轮，采用公开Alpha158配置；CPU限制2线程并固定种子。标签/数据/日期/预处理和线程数与官方例子不同，不能称完整复现官方收益。
- 每折若训练期全缺/恒定特征，只依训练期剔除并记录；未知行业独立指示，不能学习未来行业类别；不按全期有效性筛特征。
- 先验收完整第一折，不把小样本工程测试当全期验证。完整历史仍是研究样本；截至2026-11-12之前的未看月份也不能凭空宣称严格未见。
- 不强制每季IC正、不按科技比例选赢家。N2保留全部结果；N3共同评估净收益、夏普、回撤、换手、成本敏感性和分期稳定性，区别点估计改善与可持续证据。

## 3. 可复用来源

## 4. 停止发散与失败处理

任何失败给出本阶段可复现证据，先修实现/数据错误；模型效果差保留结果，不偷偷换目标或反转分数。每阶段产物都有唯一结果文件和下一项依赖，不以基础设施完成冒充策略改进。N6可在明确实验身份下上线独立模拟，但盈利晋级必须等待冻结后的真实前瞻证据。

## 5. 可运行入口

环境使用现有`.venv`，无需改生产依赖。所有输出目录不可覆盖，失败产物保留后换新目录。

```powershell
.venv/Scripts/python.exe scripts/build_ashare_mainline_panel.py --output state/ashare-mainline-20261112/panel-v1
$env:PYTHONHASHSEED='42'
$env:OMP_NUM_THREADS='2'
$env:OPENBLAS_NUM_THREADS='2'
.venv/Scripts/python.exe scripts/train_ashare_mainline.py --fold 2025Q1 --output state/ashare-mainline-20261112/first-fold-v1
```

不传`--fold`执行注册的7折×4组；首折是工程验收而不是全矩阵结果。后续正式全矩阵使用独立新目录。原生模型3个子模型在2线程下训练，特征重排评估耗时显著，不并行挤占在线服务。

正式矩阵已用以下入口启动：`scripts/train_ashare_mainline.py --inputs state/ashare-mainline-20261112/panel-v2 --output state/ashare-mainline-20261112/registered-matrix-v1`。每阶段`progress.json`记录进程ID、已完成数与更新时间；完成时生成`results.json`，失败明确标记FAILED。不是后台调度器或服务守护，不承诺电脑重启后自动续跑。

首版财务覆盖：EP89.09%、BP99.81%、ROE99.83%、营收同比99.67%、ROE变化99.63%、营收变化98.41%。12—1月动量72.08%；首折训练期全部缺失，按只看训练期的规则剔除，不能从后来补齐的值反填。现金流、毛利、杠杆未接入，不能称财务全面覆盖。保留3591条缺失20日标签行用于推理，学习时明确排除。

首折线性模型出现float32病态矩阵警告，独立float64复核排名相关0.99999998。后续正式矩阵已改为float64求解，固定Ridge系数不变；首折工程产物保留，不包装成精度修正后的正式全期结果。
