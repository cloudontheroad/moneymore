# 1103双路：2026年前九个月亏损归因

## 结论

当前证据支持“微弱预测没有充分转成持仓收益，叠加高交易摩擦”，不支持把全年亏损统一归咎于科技板块。B的风格约束确实降低波动，但仍有个股损失集中、调整残差与执行阻塞。不能通过调低滑点假设、美化暂停日或再加科技硬配额宣布问题已解决。

本次仅分析，不修改模型、策略、生产计划或账户。口径沿用独立回测：训练不晚于2025年底，2026年1—9月181个交易日，各1000万元，10bps单边滑点，原佣金税费。是冻结策略框架的研究回放，不是当前11月模型的历史实盘表现。历史池含沿用快照，财务原始版本不能完全追溯。

## 4. 信号与同风格选股不是一回事

177个已到期的5交易日信号，整体平均RankIC约+0.0270；行业和上市板块分组去均值后的偏秩相关约+0.0249，覆盖96.48%的观察行。说明模型不是完全没有排序信息，也不能说正IC完全来自行业/板块。但幅度弱，标签重叠，不是177个独立试验，更不证明能覆盖交易成本。

另用前一日信息匹配：同申万一级行业、同上市板块，按规模、动量、波动、贝塔、特异波动、估值、分红、质量、成长寻找近邻。缺失财务仅在匹配距离中使用中性分位并加缺失标记，不伪造原始财务零值；不使用未来收益挑选或替补近邻。

## 5. 执行阻塞需要单独处理，不能替模型开脱

A有28日输入/持仓风险保护暂停换仓，这些日期合计反而盈利14.18万元。因此“A主要因为暂停没交易而亏钱”的解释不成立。

B有44日暂停：

| 状态 | 日期数 | 当日实际持仓净损益合计 |
|---|---:|---:|
| 整数求解在预算内未给出合格方案 | 16 | -68.76万元 |
| 持仓风险/分数输入保护 | 20 | +22.18万元 |
| 原生优化换手约束未通过 | 8 | -5.41万元 |

44日合计约-51.98万元，其余可执行日期合计+24.25万元。这里包括回测的60秒求解预算等研究执行器条件，不等同于线上故障。暂停日亏损绝不等于暂停造成的损失；要证明补执行能改善多少，必须另做同约束、同报价的连续反事实回放，不能直接加回68.76万元或51.98万元。

## 6. 收敛判断

1. 已确定：现有持仓收益不足以支持当前交易摩擦。不能靠调低成本假设宣称优化成功。
2. 已确定：实际持仓的亏损分布不支持一刀切“科技过多”；需要检查具体排序到持仓的转化，而不是再堆科技配额。
3. 已确定：B降低风险，但有个股损失集中、调仓残差和执行可行性问题。加上风控不等于获得可交易Alpha。
4. 尚未证明：暂停换仓的净因果损失、替代成交时点能增加多少收益、改模型后能提高多少。此次没有建立新候选、没有改策略或重刷任何收益。
