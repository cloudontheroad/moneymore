# T系列：成本感知调仓与B执行收敛方案

状态：方案已制定，尚未改变生产策略、账户、计划或风险限制。日期：2026-11-04。

## 1. 唯一目标与范围

同一个冻结预测器，减少没有经济理由的调仓，让实际持仓获得的收益足以覆盖成本；独立解决B的输入、可行性与求解阻塞。不以增加科技配额、重训多个模型、调低滑点或长期不交易制造改善。

本轮只改1103A/B的信号到持仓、订单翻译和执行可靠性。基线、1029、宏观仓位与日内择时策略不联动。候选池、预测器结构、既有风格风险预算与总仓位安排作为对照冻结；不新增行业袖套，不增加固定科技比例，不增加仓位择时规则。首次配置和整手自然现金单列，不能为了100.000%投资率制造小单。

证据起点：A原成交加回税费/10bps滑点后仍-1.7419%，交易摩擦-3.6652%；B加回后+0.9900%，摩擦-3.7633%。不是成本没记账，而是尚未按经济价值决定是否付这笔成本。归因见《MATURE_LOSS_ATTRIBUTION_20261104.md》。同分修复只解决分辨率，不能替代本轮工作。

## 2. 已核对的代码与成熟参考

- 现有`mature_multifactor.py:topk_dropout_targets`保留原仓权重、限制每次替换数量，并非强制每天换五只；但没有判断换出/换入的收益差是否覆盖金额成本。不能把TopK限制冒充成本控制。
- 现有`enhanced_indexing.py`调用Qlib原生EnhancedIndexingOptimizer，目标是收益分数与风险，另有限制换手的约束；`scale_return=True`是波动率缩放，不是可直接与bps成本比较的收益校准。
- 现有`integer_execution.py`已计算手续费、现金及整手可行性；主要目标仍是追踪目标，随后改善投资率。它不是完全忽略费用，但缺少“维持原股数”和“付费调仓”的经济比较，二次投资率目标也不能越过这一比较。
- Qlib保持主体、命名风险模型和约束来源：[原生优化器](https://github.com/microsoft/qlib/blob/main/qlib/contrib/strategy/optimizer/enhanced_indexing.py)。
- 成本进入优化目标，参考[Cvxportfolio成本模型](https://www.cvxportfolio.com/en/1.3.1/costs.html)及[成熟凸优化框架](https://stanford.edu/~boyd/papers/cvx_portfolio.html)。不迁移整个系统，也不照搬其美股默认费率；集成前核对接口及许可。成本适配是需要明确实现的新能力，不能称作Qlib原生已有。
- 保留区间参考[pysystemtrade生产设计](https://raw.githubusercontent.com/pst-group/pysystemtrade/develop/docs/production.md)：每日更新预测与目标，只有当前仓位离开保留区间才产生交易。复用机制，不复制期货参数或固定百分比到A股。

## 3. 决策合同：比较交易与维持原仓的增量价值

核心是同一决策期限H内：增量预期收益－增量风险代价－全部交易成本。比较对象是实际持仓加已知公司行为权益，不是昨日目标权重。A保留自身排序对照语义；B额外服从其原有风险约束。

### 3.1 分数必须先有可解释的收益单位

1. 第一版不调预测器结构、种子、TopK或五日预测期限；不设强制持满五日/每五日换仓。
2. 统一信号时间、入场时间、到期时间。既有标签是信号日收盘到未来收盘，校准目标需对应下一交易日实际可成交入场至到期的总回报；公司行为、不可成交与缺价明确处理。
3. 用既定算法按时间折生成真正样本外预测，归一化、填充值与模型拟合均限于折内过去数据，按标签实际结束时间清除跨界样本。不能拿最终模型在训练集内的预测拟合校准曲线。
4. 第一版只做固定的线性收缩校准，将分数差映射到可成交预期收益差。收益均值的估计误差与未来价格波动分开：前者保守收缩，后者进入风险模型。不能用总波动的置信下限把所有交易永久挡掉。
5. 校准关系弱就向零收缩并明确证据不足，不强制正斜率，不反转信号或放大分数来凑交易。校准按模型、处理器、数据截止日和持有期限绑定；每周换模型时不得静默沿用旧映射。
6. 历史对照所有校准与参数决定限于2025年底前；当前部署版本仅使用其截止日前已成熟的标签。2026年1—9月已经看过，只能叫回顾性对照，不再冒充未见样本。

### 3.2 一个共用的金额成本接口

复用现有`transaction_fee`、`execution_price`、精确最低佣金与卖出税费。连续层采用合理的保守凸近似，整数层用精确金额复核。输出佣金、税、过户费、执行短差与合计，预估、计划和撮合使用同一版本。

正式对照保留10bps单边执行短差，不靠调小假设翻红。该短差暂视为价差/冲击/延迟的合并预算，不能再重复叠加相同价差。以后只有独立盘口和实际执行观测足够时才拆分/校准；不能拿按10bps生成的模拟成交反过来“证明”真实滑点为10bps。

### 3.3 交易原因分流，不能一条门槛包办

| 类型 | 处理 |
|---|---|
| 首次配置、资金变动 | 按既定资产配置和风险预算单列，不把首次配置误当作从现仓换股；允许整手/费用自然现金 |
| 明确退出池、必要风险修复 | 优先验证安全可执行性，不要求短期收益为正；“缺数据”不是“退出池” |
| Alpha换股/主动加减仓 | 比较整个交易篮子与维持原仓的成本后增量效用；优势不足不交易 |
| 单纯价格漂移、排名微变 | 在保留区间内维持股数，不为了重贴旧目标权重反复买卖 |
| 故障后的补偿 | 关联原交易意图，以最新有效目标、真实持仓及未成交量重算；不盲目重发旧单 |

保留区间由成本、预测差及风险边界形成，不先拍一个统一0.5%或一手阈值。新增与保留采用不同触发边界，避免边缘排名反复进出；批次净额合并同一账户反向单。不能在组合优化后逐腿随意删单，破坏现金或风格约束；删减需重新验证整个组合。

单笔解释示例仅用于说明，不是参数：换出换入10万元，预计增益400元，全部成本300元，均值估计不确定性折扣150元，则可选换仓不做。风险必要单另行核算。

### 3.4 经济判断必须穿透整数执行

- 把保持实际股数作为合法候选；已有安全仓位不会只因开盘跳空而被要求恢复昨日比例。
- 连续目标与整数目标均保留成本后的经济比较。不能连续层决定少动，整数层又因追踪误差/最大化投资率产生额外小单。
- 优先级为交易物理约束与必要风险修复、经济效用、减少不必要交易/成本；投资率只是满足既定配置容差后的次级考虑。
- 不设“100股永远不交易”或“单笔低于固定金额永远不交易”，大股票的一手可能足以改变风险，小股票的一手可能只是噪声。
- 真实持仓、已成交和未成交量一致读取；下单差额扣除已受理的剩余委托。风控不能把待卖视为已卖或预支未到资金。不跨独立模拟账户净额。

## 4. B的三类阻塞：独立工作流

### 4.1 输入与监控池

候选池是研究范围；持仓、待成、退出中的证券是必须持续监控的执行范围。四维图新退池后行情中断的情形不能再复现。

分开处理：不能评分但可估值/交易；停牌已证实；价格/可卖量未知。缺Alpha不自动当预测零值、不擅自清仓；必要风险减仓若有可靠行情与约束可独立验证。未知价格不填零、不无证前填，不把不可信估值显示成正常净值。不能让一个不必要的Alpha字段缺失无差别冻结所有安全动作。

### 4.2 连续约束可行性

先检查当前组合、换手预算、停牌/T+1锁定、退出要求及风险边界能否共同满足。原生优化器移除换手约束的结果仍不得静默接受。

区分物理不可行、市场漂移导致现仓已越界、普通Alpha优化无解。若需过渡修复，必须有独立版本合同、明确违反了哪一项既存边界、修复方向和期限；不能通过扩大其他风险或悄悄放宽正常预算完成下单。不承诺所有44日都必须成交。

### 4.3 整数求解与可执行结果

先产生并验证安全可行解，再在预算内改善经济目标；复用现股数/已验证方案，检验求解器是否真正接收热启动，不把变量赋值当成热启动完成。缓存不变矩阵、合理收紧变量界、数值尺度预处理，所有改动做等价性验证，不缩减必要风险资产以取巧。

限时不是已证明不可行。已有满足全部约束的候选可明示为次优：Alpha单还需满足预先确定的净收益与求解误差预算，风险修复单按其专门标准验证。不接受任意可行解或未经核验的小数舍入单。

超时后的处理是保留明确状态、可验证的风险修复子计划或保持原仓并告警，不能伪造“无交易机会/执行完成”。独立计算worker、短事务落账、有限重试、幂等计划；求解失败不重启API，不占数据库写锁等待长时间求解。数据更新后重算剩余差额，不重复买卖。

## 5. 交易解释与无效换手评价

每个决策批次记录：模型/校准/成本版本，预测时间与期限，实际股数/未成交量，原始建议、保留区间、最终股数，预期增益（元）、成本（元）、风险修复原因、净优势和选择“不交易”的理由。

订单状态分开显示：经济上无需交易；输入故障；有证据的不可行；求解超时；部分执行待补偿；已完成。前端只展示结论，不堆训练中间过程。不能用“今日0笔”掩盖失败。

事后按完整买卖批次与同期“不做本批次”的原仓差额核对H期限边际效果，计入分红、现金和费用；这是局部对照，不冒充整条策略反事实。强制风险交易单独评价，不因为短期亏损就称无效。最终因果比较仍以连续独立账本为准，不能把暂停日亏损直接加回。

## 6. 实验上限、验收和发布

冻结预测与原风险边界，只做组件消融：原A、A成本感知；原B、B仅执行修复、B仅成本感知、B两者结合。T1发现旧历史回放使用当日开盘持仓权重规划，与生产前收盘规划不同，因此原账本保留作诊断，六个固定组件统一重跑“前收盘规划→次开盘执行”。不能将新结果直接减旧异口径收益。不创建四个前台候选模型，也不做参数网格。

先覆盖原16日求解限时、20日输入保护、8日连续约束失败及正常日、小单、初建、退出、停牌/T+1、公司行为的固定诊断集合；然后对已锁参数只做一次181日完整终验，成本主档仍10bps。其他成本档只作事先声明的压力测试，不挑漂亮结果。

验收：

1. 每笔资金、股数、公司行为与账本对齐，误差不超过0.01元；不伪造成交、不隐匿失效交易日。
2. 交易理由和经济门槛100%可追溯；强制动作有单列依据，普通Alpha交易不能在保守净优势不成立时被执行层补回来。
3. 原阻塞样本100%有可复现分类和安全处理结果；可解的恢复执行，真正不可解的明确披露，不要求一律强制成交。
4. 同时报告成本、净收益、回撤、风格偏离、信号兑现、执行成功率和必要修复延迟。不能只追求换手率下降，不能以长期不动省费用算通过，不设“任意降费50%”目标。
5. 阶段终态明确：通过工程与经济验证则推出最多一对成本感知模拟版本；没有净优势则如实结项为信号不足，不继续叠新公式或无限调参。工程修复与“证明盈利”分开，模拟观察不等于实盘批准。

旧历史与已发生交易保留。新版本以明确分支日继承一致的现金、持仓和权益后独立累计，不能用不同起点声称改进；不重刷旧曲线。真正独立的效果证据来自版本冻结后的前瞻新交易日。
