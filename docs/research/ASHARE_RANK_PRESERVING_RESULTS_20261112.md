# N3R最终结果：保留原排名、等权刷新与行业上限

2026-11-12完成。R1—R5全部结项：固定全特征DoubleEnsemble预测，6种组合器×10/20bps×181交易日；不是另训一个模型，也不是生产发布。

## 结论

有实质的历史指标改善：`rank_cap`（保留原排名、50等权名额、每20交易日刷新、行业主动权重上限）相对同模型原TopK，在10bps下收益提高17.82个百分点、夏普提高0.347；20bps下仍提高16.12个百分点、0.294。银行和最大行业集中度降低。

但不是全面胜出：相对原TopK，最大回撤增加4.98/5.26个百分点，波动与换手上升。它是新的收益—风险权衡，不是收益、夏普、回撤、成本全部支配旧方案的策略。可保留为后续冻结模拟候选，不根据这段已反复查看的历史自动替换生产。

收益改善主要来自“完整刷新持仓＋重置等权”的共同改变；行业上限本身并未提高收益。不能把整个提升称为行业中性化成功，更不能称为模型预测能力提升。

“创业板＋科创板”不是“全部科技行业”。这里既没有追求0含科，也没有将原来的银行偏好换成不受限的科技集中：无行业限额对照的最高行业权重达到62.22%，说明只看收益最高也不符合原目标。

### 分步归因

1. 等权刷新相对原TopK：收益＋18.95个百分点，夏普＋0.308；是刷新与权重重置的共同影响，不能再拆成单一原因。原方案20日才调仓且仅替换5个名额，新方案更充分更新持仓，但不能由这一组实验推出所有缓冲都无效。
2. 行业上限相对相同等权刷新：收益−1.13个百分点，夏普＋0.038，年化波动−1.99个百分点；最大回撤反而＋0.85个百分点。它带来集中度和波动方面的改善，并没有提高全部风险收益指标。
3. 把原始排名改成行业内百分位：两组可比对照均退步。不能只因行业分散就采用；这只是在本窗口观察到的结果，不代表行业相对方法普遍无效。
4. 行业内百分位＋行业上限条件下，drop5成员缓冲节省约19.82万元执行成本，却损失19.02个百分点净收益。拒绝本轮这个配置；未测试“原始分数＋行业上限＋缓冲”，不能泛化到所有成本控制方法。

换手增加并非免费：`rank_cap`扣成本前后使用同一账本，本表收益已经包含增加的成本。20bps压力结果仍改善，但不能因此证明任何资金规模下都能成交。

`rank_cap`一、二、三季度净收益：10bps为0.07%、11.52%、14.56%；20bps为−0.31%、10.89%、13.77%。并非每季都更好，也没有用较低总股票仓位伪造更好的回撤。

## 行业内预测诊断和限制

161个标签已成熟的信号日：原始RankIC均值0.1220；去行业均值后0.0969，描述性20日区块95%区间[0.0079,0.1922]。说明该样本内不全是行业差异，但这不是实际净收益归因，也不是可交易超额收益。

Top50相对同日行业标签基准的20日超额均值约1.11%，区间跨零，不能称为稳定选股优势。全池严格日收益基准存在行情/市值缺口，本轮没有用缺失填零或算一个不完整的“市场超额”。现有Top1000历史沿用已有成员区间，不声称原始历史时点每日重建；行业约束所用总市值也不等于自由流通市值。

这段2026历史已经反复查看；`rank_equal`是在首版结果后补充的解释性对照，已明确登记，非未见样本。`rank_cap−TopK`的10bps收益差95%区间为[−14.61,+83.72]个百分点，夏普差为[−1.261,+1.736]；20bps也跨零。使用同日配对20日环形区块、2000次重采样、种子42，未做多重比较校正。历史点估计改善，不等于已经证明未来稳定提升。
