# 分红缺失组冲突的恒等分解

## 已确认的原因

风险合格池历史信号反事实组合的38组样本已完成分解，非原账户实际成交。最极端误差来自20260921→20260922的主GRU轨迹：300395分红数据从缺失变为已观测，而不是价格风险突然恶化。此处只能确认缓存数据的可用性标签变化，不断言实际公告事件或供应商缺失的原因。

其信号日目标权重约2.934%，下一开盘分配后、收盘价格重估权重约2.996%。缺失组主动暴露变化分解如下，单位为百分点：

| 分量 | 贡献 |
|---|---:|
| 同标签下持仓价格漂移 | −0.138805 |
| 持仓标签由缺失变已知 | −2.996473 |
| 同标签下基准权重漂移 | −0.038441 |
| 基准标签迁移 | +0.109752 |
| 基准新增/退出成员 | 0 |
| 合计 | −3.063967 |

0812候选同日亦有该标签迁移，下一收盘权重约1.495%。38个分红组案例只有这两个持仓标签迁移案例，不能把同一天两条相关模型轨迹当两个独立市场事件。

## 定义与核对

主动缺失暴露为`持仓权重·缺失指示 − 基准权重·缺失指示`。变化严格拆为：持仓价格、持仓标签、共同成员基准权重、共同成员基准标签、基准新增、基准退出六项。

持有资产缺任一日标签时直接不可测，不填零。基准新增成员没有旧标签，单列新增项，不伪造旧标签参与共同成员分解。所有缺失组分解最大恒等残差约2.94e-16，与原暴露误差逐项对平。

14日校准样本中，仅分红组“同标签共同成员重新加权”的上/下误差幅度约0.002793/0.002787；原完整误差下幅约0.030640。前者明确排除标签迁移与成员进出，**不能替代总风险包络、不能据此声称组合通过门禁**。

## 对下一步的影响

问题不只是缺数据：将缺失组当作普通经济风格做双边中性约束，可能要求组合维持一定缺失数据股票比例；数据变完整反而触碰负向边界。它与“防止过度依赖估算数据”的质量控制目标存在职责冲突。

下一步先显式定义质量控制合同，比较现有双边约束与只控制额外未知暴露的候选合同。后者若取消下界，必须承认这是合同修订，不声称原限额未变；仍须处理数据由已知变缺失和下一日修复，不得直接跳过风险约束。任何新方案保留旧合同对照，在隔离研究中完成可行性、留出及整数撮合验证，不能直接推广到账户。
