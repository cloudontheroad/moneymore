# N3R2结果：不牺牲有效收益，更新速度与缓冲的完整对照

2026-11-12结项。用户明确接受上一轮收益提高伴随合理回撤增加；本轮不再要求每项风险指标都优于旧TopK才保留候选。研究基准仍为`rank_cap`，不是改回低收益的旧方案。

## 结论

本轮三个新增配置没有进一步提高收益或夏普，全部不替换`rank_cap`。这不是因回撤门槛否决有价值方案，而是同口径实际结果不如原候选。

保留20交易日、原始排名、完整成员刷新、等权与行业上限的`rank_cap`：10/20bps净收益27.85%/25.76%，夏普1.428/1.341，最大回撤12.56%/12.85%。低换手组虽有更低回撤，但当前用户目标不支持用明显较低收益去替换它。

## 找到了哪些值得继续研究的环节

### 1. 不是留仓小单的问题

原候选910笔成交中，50笔初始建仓、822笔换入或完整退出、仅38笔留仓调量。调量占初始建仓后交易名义额约0.315%，实际手续费与滑点合计821.31元。机械取消全部调量的成本节省仅约初始本金0.0082%，同时还会改变后续持仓，不能把它包装成大提升。

因此本轮没有开发交易带、微小订单阈值或保留旧权重的复杂优化器。主要可改进对象是成员替换的质量和信号的有效期。

### 2. 固定5只替换预算过度抑制了本轮有效刷新

20日更新下，原候选规划中的主动成员换出404个，drop5组仅45个，减少约89%。后者10bps节省22.31万元执行成本，却损失21.61个百分点净收益。它同时改变持仓，而不是只节省摩擦。

10日更新下，缓冲组相对完整刷新也降低回撤，但收益和夏普仍较差。可以排除本轮固定drop5作为直接升级；不能泛化为所有有条件的交易缓冲无效，也不意味着任何大换手都是值得的。

### 3. 快慢更新的优劣具有阶段差异，不是越快越好

|10bps季度收益|20日完整刷新|10日完整刷新|
|---|---:|---:|
|一季度|0.07%|−2.27%|
|二季度|11.52%|−0.45%|
|三季度|14.56%|20.08%|

10日组全年窗口收益少11.02个百分点，执行成本多16.39万元，回撤多5.86个百分点；20bps下同样退步。不能仅凭三季度更好就改成10日，也不能根据已知季度收益人为切换赢家。

这个阶段差异为后续“信号有效期/市场状态学习”提供了待验证问题：不同来源的信号应持续多久、何时新信号足以替换旧持仓。它还不是已经证明的改进方法。下一步沿既有N4拆分慢基本面、中期趋势、短反转，使用更早训练/验证数据判断独立增量；N5再研究状态适应，而不是在本窗口继续搜索5/7/15日或事后选季度。

### 4. 最大回撤并非交易手续费主导

原候选10bps最大回撤发生在2026-05-13高点至07-17低点，净权益损失1,471,316.22元，08-05恢复高点；期间手续费与滑点约57,603元，仅相当于亏损3.92%。22个行业分类的贡献为负。归因使用逐股收盘市值、实际买卖现金流、手续费和公司行为现金，逐日与总权益变化对账，未重复扣滑点。

这是账务损益分解，不是宏观风险因果证明。它支持把研究重点放到信号与持仓风险，而不是认为少做几笔小单就能解决回撤。
