# S6首轮：有界逐日执行回放

## 范围和时间证据

2026-10-16至21日，4个交易日、3次次日开盘。使用1010候选当时实际存档的分数，非1031新模型分数倒灌：模型研究记录生成2026-10-10，数据截止2026-09-17；16/19/20日预测均生成于当日收盘后、下次开盘前，逐份哈希固定。此选择是既定短窗工程对照，不因收益选股/选时间。

每天风险输入仅取该日及以前120个收益观察；使用当日daily_basic、按公告+1日可见的同财报期指标、有效期行业映射。可选字段估计/unknown标记不变，缺必需风险历史不填价格，不把退出候选池和缺数混作同类。财务原始供应商历史版本仍未证明，因此是EX_POST工程回放，不是严格未见样本业绩。

## 验证了什么

- 初次建仓无虚构旧基准；后续连续优化与整数规划均来自独立回放账户实际持仓。保留20%股票袖套L1换手边界，不每日重新从生产账户复制仓位。
- 使用正式PaperBroker模拟委托/卖出优先/撮合，官方日涨跌停价门控，未给开盘规划器传入当日收盘数据。每次参考价计划撮合后数量与现金必须匹配，否则立即停回放。
- 以完整命名控制相对显式市值参照中心化，逐次核对实际成交后的风格边界；未偷换等权基准。
- 独立读取SQLite成交和公司行为流水，重建每日现金和持仓；现金最大误差两档均小于1e-8元，期末数量匹配。各有2条公司行为记账；采用既有毛股息/应收权益处理，未重复加送转。未模拟持有期补扣红利税。
- 独立核对T+1：当日卖出不超过昨日结余及当天解禁上市的股票权益；全部实际成交价含滑点后仍在官方涨跌停边界内。
- 成交/委托账务对账通过，无延迟成交；生产三张账户权益表前后哈希不变；未改旧候选、未发布新账户。

32项执行相关测试通过，包含真实持仓/全现金不同换手锚点的回归用例。Qlib自带timedelta弃用警告未当作业务失败或新故障修复。

## 还不代表什么/下一步

4日不能说明预测有效、收益优于基线或风格风险长期稳健。尚无长区间同池同成本原TopK/新约束组合对照及暴露/风险贡献序列，也没有盘中部分成交/容量冲击证据。下一步扩展已有可证明预测时间戳的区间，补原组合对照、实际风格轨迹和异常场景，再讨论发布；不使用当前分数重建伪历史，不以短窗盈利越过S3预测门槛。
