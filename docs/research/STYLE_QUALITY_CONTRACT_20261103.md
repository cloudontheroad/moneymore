# 独立数据质量合同：几何可行性对照

## 实验目的与显式修订

旧合同将缺失指示与经济风格一样施加双边主动暴露限额。若基准未知权重为q，缺失组限制±1个百分点意味着组合未知权重至少q−1个百分点；即使有足够已知数据股票，也可能强制维持未知数据股票。

隔离候选合同命名为`quality_upper_only_v1`：

- 经济风格、行业/板块原限额及完整上下误差缓冲均不变。
- 未知组保留原主动上限1个百分点，仍扣除完整正向误差包络；包络包含标签变差，不只取价格漂移。
- 未知组的主动下界改为`−基准未知权重`，等价于组合未知权重的物理下界零，不再人为要求最低未知股票比例。
- 这是合同修订，明确撤销旧缺失组负向限制，不声称所有原限制未变。旧执行保护不允许把此下界伪装为“仅收紧”的证明。
- 若正误差缓冲使上界低于物理下界，仍判无解，不截断误差、不放大上限。
