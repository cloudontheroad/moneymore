# N4 完整结项：独立预测、策略配置与净额交易

结项日期：2026-11-12。计划 N4.1—N4.6 全部完成；额外完成固定权重成本对照、方向锁定的动量/反转对照。最终证据：[27账户结项清单](../../state/ashare-mainline-20261112/n4-matrix-v2/completion-v2/results.json)。没有修改生产策略、真实订单或历史权益。

## 结论

本版 N4 没有产生胜过现有 `doubleensemble_full--rank_cap` 的新组合。保留原候选，不接入这版弱来源/HRP组合。并不是因为不接受少量回撤增加：新组合在本窗口的收益和夏普明显下降，最大回撤反而更大。

新增来源必须有独立的扣费后优势；改变特征、换一批股票、使用成熟配置库，不自动等于新增有效收益。另一个重要发现是，固定短反转规则明显胜过本轮学出的短周期模型，不能把模型失败笼统解释为反转机制无效。

## 三、主要问题与证据

### 1. 来源不同，但收益未独立且预测优势不足

| 10bps，2026评估 | 基本面 | 趋势特征 | 短周期 |
| --- | ---: | ---: | ---: |
| 成熟标签平均RankIC | −0.0134 | 0.0503 | 0.0151 |
| 与原候选Top50平均重叠 | 14.10% | 18.61% | 11.31% |
| 与原候选日净收益相关 | 0.727 | 0.909 | 0.636 |
| 费用＋滑点 | 7.46万元 | 25.50万元 | 85.42万元 |

基本面模型长周期排序没有表现出正向优势；趋势特征模型换了股票但与core收益相关仍达0.909；短周期模型弱信号加上3309笔成交、85.42万元成本，20bps时成本增至141.97万元。成本金额是实际账本归因，不把加回成本等同于重新跑过零成本策略。

三路新模型的2025下半年收益均为正（12.31%/8.05%/15.61%），未阻止2026变弱。仅凭过去盈利准入不足以证明下一阶段有效。

四来源等权和HRP虽降低平均最大行业占比（10bps约12.95%/13.96%，core为21.17%），仍未改善收益/夏普。风格更分散和预测更有效是两件事，不能以低行业集中宣告策略成功。

### 2. 正收益硬门槛不稳定，成本改变了策略本身

历史正收益准入HRP的10/20bps准入名单在3月10日、4月8日、6月8日、7月7日出现差异；其中20bps在4月8日、7月7日退回core-only。于是原双成本实验混合了成本冲击与政策变化。

补充验证固定10bps生成的全部配置日期和权重，用20bps源账户及相同实际执行引擎重放：

| 对照 | 净收益 | 夏普 | 最大回撤 |
| --- | ---: | ---: | ---: |
| 10bps权重＋10bps执行 | 8.39% | 0.556 | 17.37% |
| 同一权重序列＋20bps执行 | 6.06% | 0.442 | 17.97% |
| 20bps自身重新计算权重＋20bps执行 | 19.67% | 1.097 | 14.14% |

固定配置后成本提高，收益降低2.33个百分点。后两者差异13.61个百分点来自不同配置路径及其后续持仓执行，不应归功于高成本。没有事后移动零收益阈值来挑选更漂亮结果。

### 3. “用了趋势特征”不等于“学到了正向趋势”

趋势特征模型的分数与六个月动量平均排名相关为−0.308，实际偏逆动量。因此增加不学习方向的固定规则对照：6-1与12-1动量百分位各半、五日ROC反转。两者沿用相同风控和真实交易规则，无参数搜索。

| 方向固定的解释性对照 | 10bps收益/夏普/回撤 | 20bps收益/夏普/回撤 |
| --- | --- | --- |
| 6-1与12-1正向动量，20日刷新 | 0.53% / 0.251 / 40.21% | −0.05% / 0.234 / 40.26% |
| 五日短反转，5日刷新 | 14.54% / 0.708 / 25.05% | 7.14% / 0.447 / 25.49% |

固定反转比学习短周期模型的10bps收益高20.94个百分点，说明“学习模型”不自动优于简单成熟规则；但它费用滑点104.41万元、3536笔成交，仍逊于core。其与core日收益相关约0.605，不能仅凭较低相关性认定值得混合。

固定正向动量10bps二季度+49.24%、三季度−32.25%，全年前九月只剩+0.53%，表明本窗口有很强阶段差异；禁止据此事后规定“二季度用动量、三季度换反转”。收益波动较大时，几何累计收益接近零而算术日收益夏普略正并不矛盾。

补充规则在主结果之后提出，只是机制解释，不属于原先预登记或未见样本。动量缺失期限用固定中性百分位0.5，不重分配另一期限权重；五日ROC缺失或非有限时用中性比值1.0，不伪造报价。首次适配遗漏缺失值触发保护的失败目录保留，v2重新从本金回放，没有拼接净值。
