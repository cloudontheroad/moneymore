# 覆盖偏差与整数化：本轮实际结果

## 结果与限制

证据：state/style-balance/coverage-rounding-20261102-a/results.json。

- 全字段完整过滤只剩799；在隔离研究分支，保留价格风险必需字段，对可选字段使用当期截面中位估计，并额外标记每项unknown，覆盖扩到964。36只仍缺必需风险历史，不填收益、不制造财务事实。raw-observations-unfilled.parquet保留原NaN。

- 中位估计不是已观测财务值；unknown列主动暴露为0也不代表未知值无风险。该研究分支未替代原始数据、生产缺失规则或账户。

## 风险带宽与取整

在看结果前固定四组测试：连续标准化暴露带宽0/0.05/0.10/0.20；行业及每个上市板块主动权重带宽0/1/3/5个百分点；各unknown主动暴露为0。都是测试合同，未依据含科比例选择最终参数；行业限制相对市值参照，不是等预算。

四组连续解均满足合同，有效持股数约74—95。分别以10万、100万元新现金账户作向下取整诊断，共8项：全部风格检查失败。10万仅17.71%—21.53%投入；100万47.29%—47.86%投入。扣除10bps买入滑点、万1.5佣金/最低5元和过户费测试假设后检验现金。取整并不是可执行优化，更没有核验盘中行情、停牌和涨跌停。这些低投入不能称为策略有意减仓。

## 整数规划器接续

原研究整数规划器默认使用等权截面风格参照；不能直接承接新的市值参照。本轮加入显式benchmark_weights及style_controls_prestandardized选项，校验覆盖、唯一性、非负、归一及所有风格输入有限。未传参旧路径保持不变。增加75/25参照用例，证明不再误回等权；不完整参照必须BLOCKED。相关20项测试通过。

实际以964只、100万元、0.10标准化/3pp分类带宽、unknown主动暴露0作HiGHS整数求解，10秒上限。证据：state/style-balance/integer-reference-20261102-b/results.json，结果BLOCKED / INTEGER_FEASIBILITY_USER_LIMIT。超时不是证明不可行，未接受未认证解，未放宽约束，更未发委托。a版首次因连续求解器约-9e-11负零被严格目标检查阻断，b版仅作<1e-8有记录的数值归零并重新检查全部原合同，不抹除失败轨迹。
