## 小实例：可以证明而非猜测

两只股票均10元，100股一手，1万元现金，含滑点/佣金/最低收费后最多买9手。枚举所有可负担手数组合，并与HiGHS整数求解核对：

| 未知组参照权重 | 允许主动偏离 | 穷举/求解结论 |
|---|---|---|
| 37% | 0 | 不可行 |
| 37.5% | 0 | 可行，3/8 |
| 37% | 0.5个百分点 | 可行，3/8 |
| 37% | 1个百分点 | 可行，3/8 |

四项一致。说明严格零偏离可能与手数格点冲突，但不证明964只的严格合同无解。
