# 基线与挑战者风格审查（2026-10-26）

## 结论与边界

两边都没有上市板块硬配额，但两边都不是风格中性策略。基线的偏价值、分红、低风险来自明确公式及数据缺失后的权重重分配；挑战者的偏科创/创业板在原始预测排名中已经存在，伴随近期反转偏好、跨组分数尺度差异以及缓慢换仓的延续效应。不能将任何一边解释为“模型客观选出了绝对最好的股票”。

本次只读审查，没有重新生成委托、替换模型、修改权重、回刷收益或补做历史成交。新增审计脚本只写诊断文件。原始评分使用当时保存的报告；因子分项与消融实验使用数据修复后的重建快照，明确不是原始分项归档。

## 1. 先分清口径

“科创板/创业板”是上市板块，不等于科技行业。本报告STAR包含688/689，ChiNext包含300/301。科创板有医药，主板也有电子、通信、半导体。

当前统一1000候选为主板711、科创149、创业140，后两者合计28.9%。基线当日保存的有效评分999只，其中科创149、创业140，说明没有通过评分入口排除这些板块。主GRU评分983只，科创142、创业135，合计28.18%；因此不是可评分池本身先变成了多数科创/创业板。

这解释“今天评分已变化，为何持仓仍偏”：原始排名、计划目标、实际持仓是三个不同层次，不能混用。

## 3. 为什么基线0%

### 3.1 明确的隐含风格，不是没有偏好

当前固定因子权重：估值/分红36%（盈利收益率16%、账面市值比10%、股息率10%），质量/成长28%（ROE16%、营收增长12%），动量22%，低波动/回撤14%。权重不是这轮样本外自动学出的，也不是Qlib给出的通用最优公式。

当日保存分数：主板平均+0.0690，创业板−0.2419，科创板−0.3053。原始前50全为主板；最佳科创股688009排名64，最佳创业股300628排名152。因此0%首先由评分形成，并非相关性过滤或整手下单造成。

### 3.2 更严重的数据覆盖不足

本地fina_indicator只有143只股票记录，当前池命中131只，最新公告日期停在20260829。当前重建999个评分中，ROE仅129只可用、营收增长仅127只可用；只有121只具备全部因子。684只的有效权重仅0.72，主要因为质量/成长的28%缺失。

代码对每只股票按其非缺失因子的权重重新归一化。因此缺少质量/成长、其他因子完整时，估值/分红实际占比从36%变成50%，动量从22%变成30.56%，低风险从14%变成19.44%。股票之间甚至不是同一套完整评分公式。不能把“没有财务数据”当作中性或基本面差；也不能声称当前基线已完整落实质量成长体系。

可用率（ROE）：主板15.21%、创业7.86%、科创6.71%。这意味着候选池扩大后，财务覆盖没有同步扩大，风格比较混入了不对称数据覆盖。不能仅凭这点量化它造成全部收益差，但必须作为数据与研究门禁缺陷处理。

### 3.3 名义市值中性化实际未执行

preprocess默认neutralize_size=True，但registry.compute输出只保留date/symbol/因子，不保留total_mv；实时快照也没有把total_mv补回。industry_column显式为None。因此这一条实时基线没有实际市值或行业回归中性化，不能以默认配置声称已经风格中性。

### 3.4 分项与消融验证（诊断反事实）

修复数据后重建的平均得分贡献：

| 因子组 | 主板 | 创业板 | 科创板 |
| --- | ---: | ---: | ---: |
| 估值/分红 | +0.0647 | −0.2048 | −0.2490 |
| 质量/成长 | −0.0025 | +0.0092 | +0.0042 |
| 动量 | −0.0169 | +0.0208 | +0.0258 |
| 低风险 | +0.0241 | −0.0684 | −0.0875 |

质量/成长均值很小不代表经济作用小，而是大多数股票缺失。动量反而有利于科创/创业板，但不足以抵消估值与低风险扣分。

诊断删除估值/分红后，原始前100由99主板/1科创变成81主板/11创业/8科创；前10仍全是主板。单删低风险、动量或质量组也没有让前10出现科创/创业板。因此不能声称只改某一个权重就解决；前排集中是多因子共同作用加上缺失覆盖所致。

重建与原始999只分数的Spearman相关0.99799，但个股最大绝对差0.3076；重建分项只能解释结构，不能冒充历史原始分项或直接替换现有计划。

## 4. 为什么挑战者偏科创/创业板

### 4.1 学到的近期反转倾向，而非笼统“追科技”

输入是12种价量变换的60期滞后，不包含ROE/股息/估值。10月26日评分与过去20期复权收益的横截面Spearman相关：

| 模型 | 相关系数 |
| --- | ---: |
| 主GRU | −0.339 |
| 0829 | −0.399 |
| 0905 | −0.277 |
| 0912 | −0.672 |
| 0919 | −0.479 |
| 0926 | −0.652 |
| 1003 | −0.517 |
| 1010 | −0.627 |

主GRU在上述11个观察日全部为负（约−0.228到−0.710）。这支持模型存在近期反转偏好，但相关性不证明完整决策因果；价格特征互相关联，不能把它命名为已验证有效的反转策略。0829至1010候选的波动相关为正，主GRU当日略负，不能把所有模型统一说成“只买高波动”。这些风格特征的计算使用现有修复后行情，停牌/缺失区间不保证20条记录等于20个交易日，是辅助描述，不是严格因果回归。

### 4.2 高分上尾不等于高置信度

主GRU主板评分标准差0.000599，科创0.001082；0829为0.002708对0.006397；1003为0.002073对0.004557。即使均值没有更高，分布更宽也更容易进入全球最高分尾部。

主模型和旧候选manifest为多种子原始预测平均；1010实际为50%LightGBM排名加50%GRU排名的daily_rank_blend，并不是另一份纯GRU。全局百分位融合只统一模型间量纲，不消除板块/行业的分布偏差。

仅用于诊断的板块内均值/标准差校准后，再全局取前10：主GRU的科创/创业板从4降为2，1010从10降为0，1003从9降为1。这表明分布位置与尺度值得审查；**这不是建议上线板块标准化**，否则会悄悄引入新的板块相对选择目标，且会删除潜在真实信号。需要滚动样本外检验评分校准与条件收益关系。

### 4.3 训练目标与组合目标不完全一致

标签为未来5期原始收盘收益减去同日同sector平均；这是去行业均值，不是除以行业波动，也不是风险调整收益。推理随后跨行业全局直接排序。行业均值去除并不保证分数跨行业可比，也不保证模型预测实现了行业中性。当前983评分分成93个sector，17组只有一个评分股票；训练时若一个行业-日期组仅一只，其标签会机械归零（当日评分组计数不等于当时训练组计数，后者仍需单独审计）。

此外现有输入与标签基于raw_close，除权除息跳变可能污染价量特征与收益标签；近期已修复的交易日缺口对齐没有重新训练旧模型，也不会自动消除旧模型学到的问题。其影响大小尚未通过同数据重训对照确认，不能宣布为唯一根因。

### 4.4 组合层没有消除共同风格

相关簇最多3只不等于同板块最多3只，更不等于风格风险预算。当前correlation_penalty=0；相关簇约束在无候选可填时还有回退分支。因此不能以“做了相关性分散”推断已经控制科技、反转或高波动共同暴露。持仓分数到softmax权重的转换也不是预测概率或经过验证的置信区间。

## 5. 与收益证据衔接

见CHALLENGER_EVIDENCE_20261026.md：10月12收盘至26收盘，基线−5.00%、主GRU−14.97%、1010−12.73%。同风格近邻归因中，基线风格贡献约+2.83个百分点，主GRU−5.15个百分点；主GRU另外还有约−5.57个百分点选股残差，1010选股残差约+1.08个百分点。

因此既不能说“全是科技市场跌，与模型无关”，也不能说“所有候选都没有选股能力”。短样本、重叠标签与匹配假设限制仍在，必须持续前瞻验证。基线这轮受益于防御/价值倾向，不证明它无偏或长期绝对胜出。

## 6. 建议实施顺序（尚未执行策略改动）

1. 补齐1000池的时点财务数据与更新链路，建立各输入覆盖率/新鲜度门禁；禁止缺失后静默改变模型经济含义。明确旧基线保留对照，新修复版本独立前瞻，不回刷历史。
2. 保存每日原始因子、变换后因子、有效权重、原始排名、构建后排名、目标、持仓，避免只能事后重建。修正“开启中性化却无控制变量”的可观测性，是否真正中性化需研究协议决定，不直接修改生产。
3. 按候选、板块、行业、市值、波动、近期动量分层验证预测分数与未来收益；检验上尾是否有真实收益、是否只是尺度优势。比较基线/候选相同风格条件下的增量选股能力。
4. 预注册对照训练：相同池/日期/费用/种子，比较复权且日历对齐输入、现有行业去均值标签、风险标准化标签及跨组校准。严格purge/embargo和样本外分段，不能用本轮结果反复择优后冒充独立证据。
5. 只有独立前瞻证据支持时才修改训练或组合协议；不用拍脑袋科技配额、板块等权或“最近跌得多所以禁买科技”处理。
