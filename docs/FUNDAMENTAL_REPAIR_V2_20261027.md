- 候选评分仅允许全池核心财务字段完整且未过期后计算，其他因子缺失、行情日不一致仍阻断资格；不自动调仓或晋级。缺数据应调查来源，不通过改为低门槛或隐式填充掩盖。

原基线继续旧公式及原财务表；新版本只研究，不与旧账本合并。未新增行业配额、未改变现有模型训练目标、未执行新模型训练、未回刷历史收益。原版市值控制变量缺失的问题先如实暴露，不把补传市值悄悄当作没有策略变化。

## 重要限制

1. 进程存活不代表补数完成。以 `state/fundamental-research-v2/checkpoint.json` 和 `quality.json` 为准。存量运行中的首次补数任务仍使用启动时加载的整行覆盖统计；网页读取最新研究表按新逐字段规则重新计算覆盖，不将两个数混为同一口径。后续任务使用新规则。
2. 服务商可能不提供某些最新单季度指标；旧有效值超过期限仍会阻断。完整记录数不等于所有字段完整，抓取成功不等于可训练。
3. 补回的历史财务记录具有公告日期，不自动等于保存了当时原始公告版本。采集后快照有版本证据；首次采集前的潜在历史修订偏差仍需披露，不能包装成纯净前瞻数据。
4. 修复版仅财务完整还不够：负PE、未分红、上市不足长周期等因子缺失可能有经济含义。后续须明确每类处理协议，再独立前瞻；不会自动放宽门禁来获得排名。
5. 200天守卫不是完整的财报披露合规检查；后续可增加逐公司应披露期与公告日历，不以当前守卫声称所有数据均最新。
