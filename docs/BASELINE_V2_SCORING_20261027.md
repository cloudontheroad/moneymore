## 评分契约

1. 继续使用原九因子权重，先不同时调整权重与风险预算。
2. 评分为 `sum(normalized_factor * declared_weight) / sum(declared_weight)`。
   任何缺失或非有限因子逐股列明，不以剩余权重重新归一化，不补零。
3. 财务采用隔离修复表，沿用披露日+1日；按字段记录报告期、披露日和来源，超过200日账期阻断。
4. 行情限制至指定日期，并检查截至该日253个交易所开市日均有有效收盘和复权因子；不跨缺口压缩计算。
   停牌若缺交易日也暂列排除，未将缺数默认为停牌。
5. 市值使用严格早于截面日、10自然日内的已知数据；控制版将真实total_mv传入原MAD/OLS/排名处理。
   缺市值、横截面不足、退化控制变量均不悄悄忽略。
6. 两个新版处理组使用同一完整样本；无行业配额、行业中性或总仓位公式。

## 输出与首轮结果

各次运行生成独立时间戳目录，`latest.json`仅为最新指针；Parquet产物哈希和代码哈希入档：

- `legacy.parquet`：旧公式和旧财务源。
- `repaired_data_legacy_formula.parquet`：只换财务源，旧公式不变。
- `raw.parquet`、`financial_provenance.parquet`、`factor_exclusions.parquet`：原始因子、来源、逐股排除证据。
- `repaired_fixed_weights.parquet` / `repaired_size_control.parquet`：相同样本、权重，仅市值控制开关不同。
