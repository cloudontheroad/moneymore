## 仍然阻断发布的事项

1. 早期历史可评分覆盖最低80.2%，测试期92.4%—96.1%；不符合预注册全时段90%门槛。财务覆盖早期多为97%以上，剩余剔除还含价格连续性、新股历史和行业缺口，不能全部误称财务未补齐，需要继续分类审计。
2. 固定及滚动学习权重的改善尚未通过稳健性检验；不降低门槛或重复试测试集直至通过。
3. 当前接口历史财务可能包含事后修订，尚未取得完整原始版本证明。公告时间约束不能消除所有修订偏差。
4. 尚未完成连续持仓、整数股、费用、换手、涨跌停与公司行为一致的完整执行回测。当前篮子代理不能替代这项验收。

因此暂不发布“最终V2”。下一步先审计历史价格剔除原因与原始财务版本边界，再补连续执行回测及风格/收益分解，最后按冻结协议决定是否发布；不是继续对10月行情试权重。
