# 实际成交后的风格暴露与收益归因

## 验收结果

已对最新44条研究路径中的26条完整路径进行只读审计：按逐笔成交及公司行为流水重建每个收盘持仓、现金和权益，而不是使用最终持仓倒推。全部末日持仓与SQLite账本一致，逐日现金/权益最大差异约3.5e−10元。三组生产权益表哈希前后相同。

23条路径完成全部10个相邻交易日的匹配归因。主GRU、0812、0822的保存目标路径因部分持仓缺120日风格特征，分别只有8/7/7个可匹配日，不把其部分结果拼为完整归因。其他未完成回放路径保留REPLAY_NOT_COMPLETED状态。

核心7组候选的普通PCA与可行性风格分支均可作完整对照。本窗口仍为20261012—20261026，未增加样本外证据或修改原模型。

## 实际暴露下降，不只是目标权重下降

使用实际收盘经济持股数量（含除权后待上市股票权益），以当日原始价计算权重；先剥离现金占比，测量股票袖套相对当日有效风险股票池等权基准的标准化偏离。四项特征与优化协议一致：log总市值、60日动量、20日波动、120日Beta，市值最多前推9个交易日。

七组先逐日计算绝对暴露再取账户等权平均；相对普通PCA，实际持仓平均绝对偏离下降：

| 风格 | 平均绝对偏离下降 |
| --- | ---: |
| 市值 | 61.05% |
| 动量 | 41.13% |
| 波动率 | 52.02% |
| 市场Beta | 65.86% |

这里不是收益、波动率或科技持仓比例的下降百分比，也不是“完全中性”。七组平均实际股票仓位比普通PCA更高，不存在用降低目标总仓位伪装此次风格改善的处理。

## 收益归因：改善不全来自风格

采用前一交易日实际持仓，以同上市板、在四项风格百分位上最接近的非持仓股票作参照；主口径5个邻居，另保留3/10邻居敏感性。匹配不读取次日收益选邻居。市场收益使用前日保存评分池的等权代理；它与优化器剔除风险缺数后的股票池并不完全相同，不能当成某只指数的精确跟踪误差模型。

当日股票收益代理采用原始价格和官方已实施除权日现金/送转，避免直接将供应商未解释的复权因子跳变当成当日收益；历史风格特征仍沿用优化器的复权历史，相关源质量边界并未因此全部消除。

## 新发现：连续目标约束不等于成交后约束

对七组共63次调仓，冻结信号日因子和价格，将次日收盘实际股数重新映射到相同基准，检查相对于优化前暴露的边界。冻结仅用于隔离市场重新定价，不能当作真实收盘估值。发现53次至少一项越过目标边界，10次在1e−5容差内；最大超出约0.374个标准化暴露单位。

因此：实际暴露整体明显下降，但严格的逐次收敛边界没有全部落地。冻结价格后仍有偏差，说明不能只解释为次日涨跌；具体需要拆分整手取整、最小可买金额、可用资金、成交顺序与未成交。当前尚未将53次差异全部按原因量化，不能笼统断言都是整手导致。涉及送转股数基准变化时跳过该冻结口径，并显式标记需要调整，不作错误比较。

下一优先级应是**可成交整数目标构建与成交后风险校验**，而不是继续调模型参数：在同预算与费用下输出合法股数，先验证实际可达风格边界，之后再谈独立前瞻部署。现有连续优化结果仍不可当实盘订单风控保证。
